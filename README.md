# 世界の絶景図鑑

日本20か所・海外20か所の絶景を紹介する、5ページ構成のWebサイトです。

## [完成版ZIPをダウンロード](https://github.com/Riraxa/sekai-zekkei-zukan/releases/download/v2026.10.18/sekai-zekkei-zukan.zip)

1. ZIPを保存します。
2. 保存したZIPを右クリックし、「すべて展開」を選びます。
3. 展開先の「世界の絶景図鑑」フォルダーにある **index2.html** を開きます。

EdgeまたはChromeで閲覧できます。インストールやコマンド入力は不要です。
HTML・CSS・JavaScript・画像は、フォルダーごと保存してください。

写真40枚・検索・絞り込み・画像拡大はオフラインでも動作します。
写真の出典と利用条件はZIP内の管理用ファイルに記載しています。
